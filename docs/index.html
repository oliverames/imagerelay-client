Built for Modern Workflows

Finder-Native Integration

Mounts as a real location alongside iCloud. Use quick search, drag campagne assets to Figma, or edit files in Premiere Pro natively.

Dataless Placeholders

Zero local disk consumption initially. Placeholder files download dynamically on double-click and clean up automatically.

Multi-Process Dynamic OAuth

Equipped with automatic token refresh, coordinated securely across processes via lock-files. Zero Keychain prompt spam.

Read-Only Stateless iOS port

Access your DAM directly inside the native iOS Files app. Completely stateless, on-demand, and lightweight.

In-Finder Metadata Editor

Edit description details, keywords, and custom file-type fields directly in a native popover window without hitting the web.

Conflict Resolution

If a file changes remotely while you have local edits, the client uploads a non-destructive conflict copy. Your work is never lost.

Architecture

Zero Custom Daemons. Fully Sandboxed.

1

Apple File Provider Core

The OS requests folders and contents. System handles virtual listings, offline caching, and resource reclamation under low space.

2

Shared ImageRelayKit Package

Contains process-safe GRDB-backed SQLite database, rate-limiting locks, and atomic config serialization across App Groups.

3

MenuBar Host Utility

Provides UI settings, registers/unregisters the domain, runs watchdogs, and handles real-time OAuth refresh exchanges.
